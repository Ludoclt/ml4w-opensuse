# ML4W OS for openSUSE Tumbleweed

A fork of [ML4W OS](https://github.com/mylinuxforwork/dotfiles) (Stephan Raabe's Hyprland dotfiles) that keeps **all of upstream's configuration** but replaces **how it gets installed**, so that Tumbleweed stays a clean, openQA-tested system:

| Upstream (openSUSE setup) | This fork |
|---|---|
| Adds X11:Wayland, X11:fonts, KDE:Qt6, a duplicate of the OSS repository and two `home:` repositories | Official repositories only, plus Brave's official repository **at low priority** |
| `zypper install` one package at a time, with Recommends | A single `zypper install --no-recommends` transaction |
| Unneeded packages (vlc, figlet, htop, xclip, zsh, tesseract, sddm…), reinstalled on every update | Curated list: `setup/opensuse/packages.txt` |
| Fonts copied to `/usr/share/fonts`, grimblast to `/usr/local` (with sudo) | Everything that is not an RPM goes to `~/.local` |
| `pip --break-system-packages` | `pipx` |
| Repository keys imported automatically | Keys shown and confirmed by hand |
| Subproject install scripts (dock, walker…) taken from `main` | Pinned scripts, reviewed by CI before each update |
| ML4W logo | openSUSE logo (can be disabled in `setup/opensuse/options.sh`) |

## What you get

A complete desktop without installing a full desktop environment: Wi-Fi (NetworkManager, `nmtui`, graphical editor, tray icon), audio (PipeWire, pavucontrol, media keys), Bluetooth (bluez, blueman), displays (nwg-displays), brightness, night light (hyprsunset), notifications (swaync), lock screen and idle management (hyprlock, hypridle), power menu, screenshots, clipboard history, password prompts (hyprpolkitagent), keyring (gnome-keyring), battery and power profiles, USB drive mounting, system monitor (btop). The `NetworkManager`, `bluetooth` and `power-profiles-daemon` services are enabled by the installation.

Applications installed once (`apps.txt`, can be removed): kitty, neovim, nautilus, gnome-text-editor (notes), gnome-calculator, loupe (images), papers (PDF). Brave comes from its official repository and becomes the browser used by ML4W shortcuts (`options.sh`).

Deliberately left out: Pinta (ML4W's default screenshot editor, heavy), Emote (Flatpak-only emoji picker), Evolution (email), sddm.

## Branches

- **`opensuse`** (default branch): the tooling. This is the only branch you edit.
  - `overlay/`: files copied on top of upstream (`setup/` scripts, package lists, options);
  - `tools/`: build, guards, synchronization;
  - `state/`: last published and reviewed upstream versions.
- **`stable`**: generated by CI = upstream's stable version + overlay. This is what you install. One commit and one tag (`2.17-suse.YYYYMMDDhhmm`) per publication.

## What CI does (daily, `.github/workflows/sync.yml`)

1. Reads upstream's stable version (the `tag` field of its `hyprland-dotfiles-stable.dotinst`).
2. **Configuration (`dotfiles/`)**: accepted automatically.
3. **Installation (`setup/`)**: if the new version changes a file that matters for openSUSE (scripts, package lists, migration), **nothing is published** and a "Review needed" issue is opened with the diff.
4. **Subprojects**: a new install script that touches nothing system-wide is pinned automatically; otherwise an issue is opened with the diff.
5. **Validation in a Tumbleweed container**: every package exists in the official repositories (or in its declared extra repository), the full installation resolves, and Hyprland is recent enough (`setup/opensuse/min-hyprland`).
6. Publishes to `stable`.

When an issue is opened: read the diff, adapt `overlay/` if needed (e.g. add a package to `packages.txt`), then **Actions → Sync ML4W → Run workflow** with `accept_tag` set to the version (or `accept_subprojects` checked). The issue closes itself once the version is published.

## Installation on openSUSE Tumbleweed

The installation uses ML4W's own installer program (upstream, not forked: it only reads
a `.dotinst` profile and deploys it), pointed at this fork's profile:

```bash
sudo zypper install git make curl jq gum
# 1. the installer program (upstream ML4W tool, installed into ~/.local/bin)
git clone https://github.com/mylinuxforwork/ml4w-dotfiles-installer.git
make -C ml4w-dotfiles-installer install
# 2. this fork's profile, which points to the stable branch of this repository
~/.local/bin/ml4w-dotfiles-installer --install \
  https://raw.githubusercontent.com/Ludoclt/ml4w-opensuse/stable/ml4w-opensuse.dotinst
```

Brave's signing key is imported from Brave's official URL (4th field in `repos.txt`), as documented by Brave.

**Update**: run the same `--install` command (the installer detects the update, backs up the profile and offers to keep your settings).

**Rollback**: download `ml4w-opensuse.dotinst`, replace `"tag": "stable"` with one of the `…-suse.…` tags and run `--install` on that local file.

**Login screen**: greetd + tuigreet (official packages), set up once by hand:
```bash
sudo zypper install --no-recommends greetd tuigreet
# /etc/greetd/config.toml, [default_session] section:
#   command = "tuigreet --time --remember --remember-session --asterisks"
sudo systemctl enable --force greetd
sudo systemctl set-default graphical.target
```
The lock screen is hyprlock (graphical, configured by ML4W).

**Keyring unlocked at login** (so Brave and other apps don't ask for the keyring password): add the gnome-keyring PAM module to greetd's PAM stack, once, by hand:
```bash
# openSUSE ships vendor PAM files in /usr/lib/pam.d; local overrides go in /etc/pam.d
[ -f /etc/pam.d/greetd ] || sudo cp /usr/lib/pam.d/greetd /etc/pam.d/greetd
sudoedit /etc/pam.d/greetd
#   after the last "auth" line:      auth     optional  pam_gnome_keyring.so
#   after the last "session" line:   session  optional  pam_gnome_keyring.so auto_start
```
The keyring password must be the same as your login password.

## Customization

- Packages: `overlay/setup/opensuse/packages.txt` (system) and `apps.txt` (applications installed once).
- Extra repositories: `overlay/setup/opensuse/repos.txt` (`alias | priority | url [| signing key url]`, priority > 99).
- Logo, browser, pywalfox, matugen: `overlay/setup/opensuse/options.sh`.
- Local test without publishing:
  ```bash
  FORK_URL=https://github.com/Ludoclt/ml4w-opensuse.git NO_PUSH=true SKIP_VALIDATE=true tools/sync.sh
  ```
